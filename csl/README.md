# Citation styles

These CSL styles come from the [Citation Style Language styles repository](https://github.com/citation-style-language/styles)
and are licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Each file names its authors
in its `<info>` block. They are bundled unchanged; layouts offer them as the "Citation style" option, and a
document can still use any other style with `csl: some-style.csl` in its front matter.

| File | Style |
|---|---|
| `chicago-author-date.csl` | Chicago Manual of Style 18th edition (author-date), the default |
| `chicago-notes-bibliography.csl` | Chicago Manual of Style 18th edition (notes and bibliography) |
| `apa.csl` | APA Style 7th edition |
| `modern-language-association.csl` | MLA Handbook 9th edition |
| `harvard-cite-them-right.csl` | Cite Them Right 12th edition (Harvard) |
| `ieee.csl` | IEEE Reference Guide |
| `din-1505-2.csl` | DIN 1505-2 (author-date, German) |

To update them, download the same file names again from the repository's `master` branch.
