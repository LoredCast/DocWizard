# Elsevier journal manuscript

A manuscript for submitting to an Elsevier journal, after the preprint format of the `elsarticle` class.
Elsevier typesets accepted papers itself, so what matters is a clean, readable manuscript.

- **Page**: A4, one column, 12 pt New Computer Modern, justified; paragraphs indented. Set the line spacing to
  2 in the layout options when a journal wants double spacing for review.
- **Title block**: title, authors, affiliations in italics and e-mail, then the abstract under "Abstract" and
  the `keywords`.
- **Headings**: "1. Introduction" in bold, "1.1. Background" in italics, level 3 italic and run in.
- **Captions**: "Fig. 1." and "Table 1.".
- **References**: Elsevier's numbered style with article titles (`elsevier-with-titles`), or its author-date
  Harvard style (`elsevier-harvard`), chosen in the layout options. Check your journal's Guide for Authors.
