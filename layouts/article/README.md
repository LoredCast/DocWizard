# Article

A journal-style article. The PDF has the title, authors, abstract and keywords across the top of the
first page and the text in two columns (switchable to one). Sections are numbered.

Front matter it uses: `title`, `subtitle`, `author` (names, or entries with `name`, `affiliation`
and `email`), `date`, `abstract`, `keywords`, `institution`.

Options: font size (9–11 pt), columns, line spacing, section numbering and citation style.
