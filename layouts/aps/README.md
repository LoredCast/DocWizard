# Physical Review (APS)

After the APS author guidelines (journals.aps.org, "Style Basics"): two columns on US Letter with the title,
authors, affiliations and abstract across the top; sections numbered I., A., 1. with level-one headings in
capitals; references numbered in order of citation, in square brackets, in one list at the end; figure
captions "FIG. 1." and table captions "TABLE I." with Roman numerals; equations numbered on the right.

Write citations right after the word, `political[@smith2019]`: the style puts a non-breaking space before
the bracket itself.

Front matter it uses: `title`, `subtitle`, `author` (with `affiliation` and `email`), `date`, `abstract`.
APS asks for an abstract of one self-contained paragraph without references or displayed equations.

Options: columns (one column for a preprint look), line spacing and the citation style.
