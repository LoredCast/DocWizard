# Term paper layout

For seminar and term papers: A4, 12 pt, 1.5 line spacing, a title page with
the institution, numbered sections and Chicago author-date citations
(pandoc's default style; set `csl:` in the front matter for another one).

Options: font size, line spacing, section numbering, title page and institution.
Everything else, including the HTML preview, comes from the default layout.
