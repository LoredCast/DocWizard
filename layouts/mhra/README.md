# MHRA essay

Follows the *MHRA Style Guide*, 4th edition (Modern Humanities Research Association). Section numbers refer to it.

- **Page and text** (1.2(a)): A4, Tinos at 12 pt (Times New Roman metrics) with 1.5 line spacing, the same size for
  notes and quotations. Paragraphs are marked by an indent, not by space between them.
- **Headings** (1.2(d)): main headings in bold, subheadings in italics, unnumbered.
- **Quotation marks** (2.13): single quotation marks, double ones for a quotation inside a quotation. The
  layout uses British English, so this follows from the language; it stays single with other English variants
  too.
- **Long quotations** (2.14): set off with space before and after, indented, without quotation marks.
- **Notes** (2.16): footnotes with superscript numbers after punctuation, in the size of the text.
- **Captions** (1.3, 1.4): "Fig. 1." below figures and "Table 1." above tables.
- **Dates**: day month year, "13 November 2026", when given as `2026-11-13`.
- **Bibliography**: under "Bibliography", with a hanging indent.

**Citations.** MHRA notes and bibliography (the CSL style `mhra-notes`, MHRA 4th edition). The author-date
system is offered as `mhra-author-date`.
