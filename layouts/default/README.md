# Default layout

Clean single-column output for any kind of document.

- HTML: a centred serif text column, used for the preview and for publishing.
- PDF via Typst: A4, 11 pt, 1.25 line spacing, page numbers.
- DOCX and ODT use pandoc's default reference documents.

Options: paper size, font size, line spacing, section numbering and a table of contents.
